생성된 코드

아래 코드를 Google Apps Script에 붙여넣고 배포하세요

Code.gs
index.html
1
Google Sheets 새 파일 생성
sheets.new 에 접속해 새 스프레드시트를 만드세요. 이름은 자유롭게 지정하세요.
2
Apps Script 열기
상단 메뉴 → 확장 프로그램 → Apps Script 클릭
3
Code.gs 교체
기존 코드 전체 삭제 → Code.gs 탭의 코드 붙여넣기 → 저장(Ctrl+S)
4
index.html 파일 추가
왼쪽 파일 목록 + 클릭 → HTML 선택 → 파일명 index 입력 → index.html 탭 코드 붙여넣기 → 저장
5
시스템 초기화 실행 (최초 1회)
함수 선택창에서 initializeSystem 선택 → ▶ 실행
권한 요청 팝업 → 권한 검토 → 고급 → 안전하지 않은 페이지로 이동 → 허용
완료 후 스프레드시트에 예약현황 시트와 초기 시간표가 자동 생성됩니다.
6
웹앱 배포
상단 배포 → 새 배포 → 웹 앱 선택
→ 액세스: 모든 사용자 → 배포 클릭
7
URL 공유
생성된 웹 앱 URL을 복사해 학부모님께 공유하세요.
⚠️ 코드 수정 후 재배포 시: 배포 → 배포 관리 → ✏️ 아이콘 → 버전: 새 버전 선택 후 배포해야 변경사항이 반영됩니다.
